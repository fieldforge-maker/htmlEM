RC 회로

축전기를 채우고 비우는 RC 회로

전류 i (화살표가 길수록 세다) ■ ΔVR ■ ΔVC 축전기 속 전기장

ℰ − qC − iR = 0

충전: q = Cℰ(1 − e−t/τ),  i = ℰRe−t/τ,  τ = RC

방전(전지 없음): q = Qie−t/τ,  i = −(Qi/RC)e−t/τ  (식 27.22, 27.23)

q(t), i(t)
값

전류는 그림처럼 저항을 위에서 아래로 지날 때 +(시계 방향). 방전 전류는 −로 나온다(식 27.23).

화살표의 길이가 전류의 세기다. 화살표가 움직이는 빠르기는 일부러 느리게 그렸다: 도선 속 전자의 실제 유동 속력은 1초에 1 mm도 안 된다.

조절

전지의 내부 저항은 0. 기본값은 교재 예제 27.7(ℰ = 12.0 V, C = 5.00 μF, R = 800 kΩ → τ = 4.00 s). 화면 속 시간은 실제와 같다.

전지가 한 일은 어디로 갈까?

전류 i □ 전지가 한 일 W ■ 축전기의 에너지 UC ■ 저항의 열 (내부 에너지) ER

W = UC + ER

W = Qmaxℰ = Cℰ2,  UC = q22C,  ER = ∫i2R dt

에너지와 일률의 시간 그래프
값

회로를 처음 닫은 때부터 쌓은 값. 막대는 Cℰ2을 100 %로 잰다.

조절

ℰ = 12.0 V, C = 5.00 μF (예제 27.7). 전지의 내부 저항은 0. 화면 속 시간은 실제와 같다.

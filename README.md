# htmlEM
전자기학 수업용 html 제작

교실 시연용 인터랙티브 화면 모음입니다. 각 파일은 그 자체로 열리는 HTML 한 장입니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 장 목록 (GitHub Pages 첫 화면) |
| `ch29.html` | CH29. 자기장의 원천: 앙페르 법칙, 솔레노이드 5개, 토로이드 2개 화면 |
| `ch30.html` | CH30. 패러데이의 법칙: 그리피스의 세 실험 비교, 갈릴레이 장 변환, 유도 전기장, 스위치·패러데이 원판 퀴즈 화면 |

`ch29.html#s8`, `ch30.html#s4`처럼 주소 끝에 화면 이름을 붙이면 그 화면부터 열립니다 (목록은 `index.html` 참고).

퀴즈가 있는 단계는 단계 번호에 점선 테두리가 있습니다. 계기판의 퀴즈 카드에서 보기를 눌러 손든 답을 표시해 두고, '정답 보기'나 → 키로 정답과 시연을 봅니다.
